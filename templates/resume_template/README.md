# Approved Resume Template

`SampleConsultingResume.pdf` is the approved fixed visual and structural template for all newly generated tailored resumes. Its content is reference material only; future resumes must substitute only accurate, job-relevant candidate content while preserving this template's design, typography, spacing, single-column layout, section rules, and bullet treatment.

## Imported template archive

`codex_resume_template.zip` is preserved unchanged in this folder. Its extracted contents are available under `imports/codex_resume_template/templates/resume/` for review. Documentation and instructions inside the imported archive are reference material only; the active project policy remains [profile/RESUME_RULES.md](../../profile/RESUME_RULES.md).
